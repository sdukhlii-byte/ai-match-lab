# AI Match Lab — генератор видео «5 AI-моделей предсказывают счёт»

Матч → реальные прогнозы ChatGPT / Claude / Gemini / Perplexity / Grok →
видео, где рука маркером вписывает счёт в бланк → zip-кит → Telegram-группа →
автопостер `coinplay-predictions-to-social` публикует в Threads, Instagram (Reels) и X.

```
fixtures.py (football-data.org: ближайший реальный матч) ──► матч
            │
            ▼
         stats.py (football-data.co.uk: Elo, форма, H2H — только клубные лиги)
            │
            ▼
         predictions.py (OpenRouter, 5 моделей, веб-поиск + статистика в промпте)
            │
            ▼
         poster.py ──► blank.jpg (пустой бланк на столе)
                   └─► filled.jpg (тот же бланк с цифрами «от руки»)
            │
            ▼
         video.py ──► fal.ai first+last frame ──► рука дописывает цифры
            │          (Veo 3.1 по умолчанию, Kling 2.5 как запасной)
            ▼
         ffmpeg: склейка + стоп-кадр 2 сек ──► video.mp4
            │
            ▼
         kit.zip (kit.json + threads/ instagram/ x/) ──► Telegram ──► автопостер
```

## Реальная статистика в промпте

Перед запросом к моделям `stats.py` тянет бесплатные CSV с
[football-data.co.uk](https://www.football-data.co.uk) (без ключа, 22 европейские
лиги) и считает по ним:

- **Elo** обеих команд (свой расчёт по всей истории сезона — CSV не даёт готового рейтинга);
- **форму** за последние 5 матчей (W/D/L, средние голы забитые/пропущенные);
- **личные встречи** (H2H) — сколько раз кто выигрывал, средняя результативность.

Эти цифры добавляются в промпт каждой модели строкой "Real stats: …", моделям
явно сказано ставить свежие новости (травмы, замена тренера) выше исторической
статистики, если они расходятся.

Лига определяется по полю `competition` — точное совпадение из списка в
`stats.LEAGUE_CODES` (`"Premier League"`, `"La Liga"`, `"Serie A"`, `"Bundesliga"`,
`"Ligue 1"` и т.д., без учёта регистра). **Не работает** для сборных и турниров без
клубного сезона (Чемпионат мира, товарищеские, Лига чемпионов) и для
эсенспорта/UFC — там просто нет данных на football-data.co.uk, и генератор
молча идёт дальше без блока статистики, как раньше.

Имена клубов, которые в CSV пишутся иначе, чем обычно ("Man City", "Man United",
"Ata. Madrid", "Paris SG") — прописаны в `stats.ALIASES`, дополняй по мере надобности.
`USE_STATS=false` — отключить совсем, если данные по лиге постоянно не находятся.

## Почему первый + последний кадр

Видео-модель, которой дали только пустой бланк, напишет **свои** цифры: не те,
что предсказали модели, и не те, что в подписи поста. Поэтому последний кадр
рендерится заранее с нашими цифрами, а модель только рисует между кадрами руку
с маркером. В конце ролика на бланке всегда правильный счёт.

## Запуск

```bash
pip install -r requirements.txt          # + ffmpeg в системе
export OPENROUTER_API_KEY=...  FAL_KEY=...
export TELEGRAM_BOT_TOKEN=...  TELEGRAM_CHAT_ID=-100...   # группа, которую читает автопостер

python generate.py --home Spain --away Argentina --home-flag es --away-flag ar \
    --competition "World Cup Final" --date 2026-07-19

python generate.py --match-file matches.json      # пачка матчей
```

Полезные флаги:
- `--no-video`: только кадры, промпт и кит с картинкой. Бесплатно, удобно проверить бланк.
- `--scores "1-2,2-1,2-2,1-0,2-1"`: свои счета без запросов к моделям (порядок ChatGPT, Claude, Gemini, Perplexity, Grok).
- `--no-send`: не отправлять в Telegram.

Всё складывается в `out/<матч>/`: `blank.jpg`, `filled.jpg`, `prompt.txt`,
`predictions.json`, `video.mp4`, `<матч>.zip`.

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `OPENROUTER_API_KEY` | — | ключ OpenRouter для прогнозов |
| `FAL_KEY` | — | ключ fal.ai для видео |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | — | куда слать кит; без них кит только сохраняется |
| `FOOTBALL_DATA_API_KEY` | — | ключ football-data.org для `--auto` (подбор реальных матчей, см. ниже) |
| `FIXTURES_COMPETITIONS` | `PL,PD,SA,BL1,FL1,CL,ELC` | какие лиги смотреть в `--auto` (коды football-data.org, через запятую) |
| `FIXTURES_DAYS_AHEAD` | `3` | окно поиска матчей в `--auto`: сегодня + N дней вперёд |
| `FIXTURES_PER_RUN` | `1` | сколько ближайших матчей брать за один запуск `--auto` (= сколько видео за прогон) |
| `MODEL_CHATGPT` … `MODEL_GROK` | см. `predictions.py` | id моделей на OpenRouter; если id пропал из каталога, берётся самая свежая модель вендора |
| `WEB_SEARCH` | `true` | веб-поиск OpenRouter для свежих новостей (Perplexity ищет сама) |
| `USE_STATS` | `true` | подмешивать в промпт Elo/форму/H2H с football-data.co.uk (только клубные лиги) |
| `VIDEO_PROVIDER` | `veo31` | `veo31` (реалистичнее, со звуком) или `kling25` (дешевле, 10 сек, без звука) |
| `VEO_RESOLUTION` | `1080p` | `720p` / `1080p` |
| `VEO_DURATION` | `8s` | `4s` / `6s` / `8s` |
| `SEGMENTS` | `1` | сколько роликов склеивать (строки распределяются поровну). Все 5 строк в один 8-сек клип — это много правок разом, модель иногда путает ячейки; `SEGMENTS=3` или `5` (по 1–2 строки на клип) даёт заметно более чистую руку, но и стоит дороже (каждый сегмент — отдельный запрос к fal.ai) |
| `HOLD_SEC` | `2` | стоп-кадр в конце, чтобы успели прочитать |
| `TABLE_IMAGE` | `assets/table.jpg` | фото столешницы; если файла нет, рисуется дерево |
| `MUSIC_FILE` | — | фоновая музыка, подмешивается тихо |

## Автоматический подбор реальных матчей (`--auto`)

Раньше матчи брались из `matches.json`, который приходилось редактировать
руками. Теперь `Dockerfile` по умолчанию запускает `python generate.py --auto` —
генератор сам находит ближайшие реальные (ещё не сыгранные) матчи топ-лиг
через бесплатный API [football-data.org](https://www.football-data.org):

1. Зарегистрируйся (2 минуты, без карты): https://www.football-data.org/client/register
2. Добавь в переменные Railway: `FOOTBALL_DATA_API_KEY=<ключ из письма>`.
3. Готово — при каждом запуске берётся самый ближайший по дате запланированный
   матч из `FIXTURES_COMPETITIONS` (АПЛ, Ла Лига, Серия А, Бундеслига, Лига 1,
   Лига чемпионов, Чемпионшип по умолчанию) в окне `FIXTURES_DAYS_AHEAD` дней.

Без ключа `--auto` откажется работать с понятной ошибкой (выдумывать
несуществующие матчи он не может). `matches.json` + `--match-file` никуда не
делись — это ручной/тестовый режим, если когда-нибудь понадобится конкретный
матч вне общего расписания.

Название турнира из football-data.org уже в том виде, который понимает
`stats.LEAGUE_CODES` ("Premier League", "Serie A" и т.д.), а имена клубов
("Arsenal FC", "Real Madrid CF") нормализуются в `stats._norm()` до вида CSV
football-data.co.uk — статистика продолжает подтягиваться, как и раньше.

## Дата матча

Дата обязательно должна быть в будущем (`YYYY-MM-DD`). Прошедшая дата означает,
что у матча уже есть реальный результат — модели этого не знают и просто
нафантазируют правдоподобный "прогноз" на несуществующее событие, поэтому
такой матч **отклоняется ещё до похода к API моделей** (деньги не тратятся).
Отключить проверку (например, для теста на старом матче): `ALLOW_PAST_DATES=true`.

## Как сделать ближе к референсу

1. **Фото стола.** Сфотографируй свой стол сверху и положи в `assets/table.jpg`.
   Чем реалистичнее первый кадр, тем реалистичнее рука и свет в видео.
2. **Иконки моделей.** `assets/icons/chatgpt.png`, `claude.png`, `gemini.png`,
   `perplexity.png`, `grok.png` (PNG с прозрачностью). Если файла нет, рисуется нейтральный значок.
3. **Эмблемы клубов** для клубных матчей: `assets/crests/<club>.png` или URL в
   `home_flag` / `away_flag`. Флаги стран подтягиваются сами по ISO-коду (`es`, `ar`, `gb-eng`).
4. **Длина.** Референс ~17 сек: `SEGMENTS=2` + `HOLD_SEC=2` дают ~18 сек.

## Оформление карточки (бренд Coinplay)

`poster.py` рисует карточку по гайдлайну Coinplay, а не generic-дизайн:

- **Цвета**: фон `#09001B`→`#1C0549` (слоистый градиент + мягкие неоновые
  «пузыри» вместо плоской заливки), панели `#2F0B76`/`#51358A`, акцент
  `#C969FF`, жёлтый `#FFE145` (рамка, счётные боксы, «маркер», от руки
  вписывающий счёт — жёлтый пигмент лучше читается на тёмной карточке, чем
  чёрные чернила).
- **Шрифт**: Roboto Condensed (Bold — заголовок, SemiBold — подписи и имена
  моделей). Статические файлы уже лежат в `assets/fonts/` (инстанс из
  переменного шрифта Google Fonts, т.к. Pillow не умеет ось `wght` "на лету").
- **Лого**: настоящий знак Coinplay из фирменного пакета —
  `assets/logo/mark.png` (белый play-круг на прозрачном фоне, взят из
  `icon-512x512.png`). Если файла нет, `_logo()` рисует приблизительную
  версию (два пересекающихся «play»-круга) как запасной вариант.
- Старые константы (`NAVY`, `LIME`, `CYAN`, `PAPER`) оставлены как алиасы
  новых цветов — если где-то ещё ссылаются по старым именам, ничего не сломается.

## Подпись поста

Генерируется из прогнозов: 5 счетов, консенсус (кто победит по большинству),
самый частый счёт и призыв «Link in bio». Для X своя короткая версия до 280 символов.
Автопостер ещё может дописать хештеги (`X_HASHTAGS`, `INSTAGRAM_HASHTAGS`).

## Деплой (Railway)

`Dockerfile` ставит ffmpeg и cairo. Сервис запускается как cron-job
(`python generate.py --match-file matches.json`) либо вручную из CLI.
Список матчей на день редактируется в `matches.json`.
